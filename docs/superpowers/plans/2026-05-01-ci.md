# GitHub Actions CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `main` への push と pull_request をトリガーに TypeScript コンパイルと Jest テストを自動実行する CI ワークフローを追加する。

**Architecture:** `.github/workflows/ci.yml` を 1 ファイル新規作成するだけ。`ubuntu-latest` + Node.js 20 LTS のシングルジョブで `npm ci → npm run compile → npm test` を順に実行する。

**Tech Stack:** GitHub Actions（`actions/checkout@v4`, `actions/setup-node@v4`）

## Task 1: CI ワークフローを作成する

**Files:**
- Create: `.github/workflows/ci.yml`

- [ ] **Step 1: `.github/workflows/` ディレクトリを作成し、`ci.yml` を作成する**

以下の内容で `.github/workflows/ci.yml` を作成する：

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'

      - run: npm ci

      - run: npm run compile

      - run: npm test
```

- [ ] **Step 2: ローカルで YAML の構文を確認する**

Run: `cat .github/workflows/ci.yml`

Expected: ファイルの内容が正しく表示される。

- [ ] **Step 3: コミットする**

```bash
git add .github/workflows/ci.yml
git commit -m "ci: add GitHub Actions workflow for compile and test"
```

- [ ] **Step 4: push して CI が通ることを確認する**

Run: `git push origin main`

Expected: GitHub の Actions タブで CI ジョブが起動し、`build` ジョブが緑になる。
