# GitHub Actions CI 設計

**日付:** 2026-05-01  
**スコープ:** `.github/workflows/ci.yml` — TypeScript コンパイルと Jest テストを自動実行する CI ワークフロー

---

## 概要

`main` ブランチへの push および pull request をトリガーに、TypeScript のコンパイル確認と Jest テストを自動実行する。

---

## トリガー

| イベント | 対象ブランチ |
|---|---|
| `push` | `main` |
| `pull_request` | `main` |

---

## ジョブ構成

シングルジョブ。`ubuntu-latest` + Node.js 20 LTS で順に実行する。

| ステップ | 内容 |
|---|---|
| `actions/checkout@v4` | コードをチェックアウト |
| `actions/setup-node@v4`（`cache: 'npm'`） | Node.js セットアップ＋`node_modules` キャッシュ |
| `npm ci` | クリーンインストール |
| `npm run compile` | TypeScript コンパイル（`tsc -p ./`） |
| `npm test` | Jest テスト（`jest`） |
